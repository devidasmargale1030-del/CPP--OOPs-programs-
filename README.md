# C++ Programs - Units 1, 2 and 3

This repository contains C++ programs organized unit-wise for submission and review.

## Structure

- `Unit-1` - Basic C++ concepts
- `Unit-2` - Inheritance and related OOP concepts
- `Unit-3` - Function/operator overloading and runtime polymorphism

## Each program contains

- Program title
- C++ source code
- Comments describing the program
- Expected output

## How to run

Compile and run one `.cpp` file at a time.

Example:

```bash
g++ Unit-1/01_Basic_Data_Types.cpp -o program
./program
```

## Note

The programs are kept as separate files because each program has its own `main()` function.
